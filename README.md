Yiamarin Apartments Website

Ιστοσελίδα κρατήσεων για τα Yiamarin Apartments, δύο διαμερίσματα διακοπών στο Ίστρο, Κρήτη.

Κατάσταση

Το project βρίσκεται υπό κατασκευή. Το responsive design δεν είναι ακόμα έτοιμο, οπότε προς το παρόν το site είναι βελτιστοποιημένο κυρίως για desktop οθόνες.

Περιγραφή

Η κεντρική σελίδα παρουσιάζει τα δύο διαμερίσματα, με ξεχωριστές υποσελίδες για το καθένα. Φτιαγμένο εξ ολοκλήρου με καθαρό κώδικα, χωρίς frameworks ή CMS.

Τεχνολογίες


HTML5
CSS3 (χωρίς frameworks)
Vanilla JavaScript
